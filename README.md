# Google Tag Manager Event Tracking Demo

This project is a simple landing page built to practice Google Tag Manager installation, event tracking, and dataLayer implementation.

## Project Overview

The goal of this project is to demonstrate how Google Tag Manager can be used to track user interactions on a website, such as button clicks and external link clicks.

## Tracking Events Implemented

| User Action | dataLayer Event | Purpose |
|---|---|---|
| Click Sign Up | `lead_button_click` | Simulates a lead conversion |
| Click Buy Now | `purchase_button_click` | Simulates purchase intent |
| Click External Link | `external_link_click` | Tracks outbound link engagement |

## Tools Used

- HTML
- CSS
- JavaScript
- Google Tag Manager
- GTM Preview Mode
- dataLayer

## What I Practiced

- Installing a Google Tag Manager container
- Creating custom dataLayer events
- Creating Custom Event triggers in GTM
- Testing tags using GTM Preview Mode
- Understanding how marketing and analytics events are structured
